# HF ALIO regulation corpus

Collected on 2026-10-12 from ALIO institution C0258, disclosure item 21110.

- 225 regulation records, 778 original attachments downloaded successfully.
- 225 latest attachment versions have searchable text.
- 776 top-level attachments have extracted text; two historical HWP files are DRM-protected and excluded from text search. See manifest.json errors.
- Historical ZIP contents are recursively extracted. Default search uses the newest standalone attachment by ALIO file number for each regulation; the historical search option includes prior versions.
- Original page numbers are preserved for PDF. HWP/DOCX extracted text has no reliable page number and is explicitly labeled accordingly.
- Corpus is gzip-compressed UTF-8 JSON, split into ordered corpus.part0000... files for deployment. SHA-256 is recorded in manifest.json and checked on load.
- AI answers use only retrieved excerpts, cite numbered sources, and fall back to clearly labeled source search when the external provider is unavailable or rate-limited.
- The original 778 files are retained in the user-facing archive HF-ALIO-225규정-778첨부.zip outside the source repository.

This is a dated collection. It does not automatically synchronize future ALIO amendments.
