# HF 인턴 퀘스트

사원번호 기반 회원가입, 관리자 승인, 로그인, 개인 체크리스트, 출석체크, 즐겨찾기, 위키, 점심 초대, 달력이 포함된 인턴 포털입니다.

공개 주소: https://hf-intern-quest.onrender.com/

회원가입에는 부서 입력이 필요합니다. 가입 승인 관리에서 부서를 확인하고 거절 사유를 남길 수 있으며, 거절된 회원에게 로그인 시 사유가 표시됩니다. 기존 회원의 부서는 미입력으로 표시됩니다.

관리자의 전체 공지 관리에서 공지를 등록·삭제할 수 있고 모든 로그인 회원의 대시보드에 표시됩니다. 달력 날짜를 클릭하면 본인만 열람하는 개인 일정 메모를 추가·삭제할 수 있습니다.

공유 게시판: 공부 모임 만들기·참여/취소, 관리자 등록 기사·채용 소식, 작성자와 관리자만 접근하는 1대1 Q&A, 건의사항 및 댓글. 기사와 채용 소식은 자동 수집하지 않으며 관리자가 직접 원문 링크와 내용을 등록합니다.

## 실행

Python 3.12 이상에서 `python server.py`를 실행하고 http://127.0.0.1:8765/ 에 접속합니다.

## 배포

Render Free 웹 서비스와 Neon Free PostgreSQL을 사용합니다. `render.yaml`에는 무료 요금제가 지정되어 있으며 유료 영구 디스크는 사용하지 않습니다. 배포 전 `pip install -r requirements.txt`로 의존성을 설치합니다.

`DATABASE_URL`에 Neon의 SSL 연결 문자열을 비공개 환경 변수로 설정합니다. 이 값이 있으면 계정·출석·개인 설정은 PostgreSQL에 저장되며 서버가 재시작해도 유지됩니다. 로컬 실행에서는 SQLite를 사용합니다.

`HF_ADMIN_SEED`는 관리자 계정의 사원번호, 이름, salt, 비밀번호 해시를 담는 비공개 환경 변수입니다. 기존 관리자 계정에서 안전하게 이전하며 저장소에 기록하지 않습니다. 비밀번호 원문은 사용하지 않습니다.

`data/`, `.env`, 데이터베이스 연결 문자열, 관리자 초기 설정 값, 비밀번호, 세션을 공개 저장소에 올리지 마세요.

무료 서비스의 사용량 한도가 적용됩니다. Render 서버는 유휴 상태에서 잠들 수 있어 다음 접속 시 시작을 기다릴 수 있습니다. GitHub의 main 브랜치에 변경을 올리면 Render가 자동으로 다시 배포합니다.

GitHub Pages는 로그인 서버를 실행하지 못하므로 이 앱의 배포 대상으로 사용하지 않습니다.

레벨은 회원별 누적 포인트, 월간 랭킹은 해당 월에 얻은 포인트를 사용합니다. 기존 예시 경험치는 이전하지 않고 0점부터 시작합니다. 랭킹은 화면이 열린 동안 15초마다 갱신합니다.

포인트: 출석 10점(하루 1회), 업무 완료 5점(같은 업무 하루 1회, 하루 최대 5건), 공부 모임 개설 10점(하루 1회), 모임 참여 5점(모임당 1회), 건의 작성 5점(하루 1회), 청소 완료 10점(회원·주·구역당 1회). 클라이언트가 제출하는 XP 수치는 사용하지 않습니다. 이 기준은 activity.py에서 변경할 수 있습니다.

순발력 랭킹은 한국 시간 월요일부터 시작하는 주간 개인 최고 기록을 사용합니다. 서버가 발급한 게임 시작 토큰으로 1회만 기록하며, 기록 가능 범위는 100~10000ms입니다. 일반적인 브라우저 게임이며 전문적인 부정행위 방지 시스템은 아닙니다.

청소 배정은 관리자가 승인된 회원과 구역을 이번 주에 등록합니다. 담당자 본인과 관리자가 완료할 수 있고, 관리자는 배정을 삭제할 수 있습니다. 다음 주에는 새 배정을 사용합니다. 이전 출석 기록과 계정은 보존됩니다.
