# HF 인턴 퀘스트

사원번호 기반 회원가입, 관리자 승인, 로그인, 개인 체크리스트, 출석체크, 즐겨찾기, 위키, 점심 초대, 달력이 포함된 인턴 포털입니다.

## 실행

Python 3.12 이상에서 `python server.py`를 실행하고 http://127.0.0.1:8765/ 에 접속합니다.

## 배포

Render Free 웹 서비스와 Neon Free PostgreSQL을 사용합니다. `render.yaml`에는 무료 요금제가 지정되어 있으며 유료 영구 디스크는 사용하지 않습니다. 배포 전 `pip install -r requirements.txt`로 의존성을 설치합니다.

`DATABASE_URL`에 Neon의 SSL 연결 문자열을 비공개 환경 변수로 설정합니다. 이 값이 있으면 계정·출석·개인 설정은 PostgreSQL에 저장되며 서버가 재시작해도 유지됩니다. 로컬 실행에서는 SQLite를 사용합니다.

`HF_ADMIN_SEED`는 관리자 계정의 사원번호, 이름, salt, 비밀번호 해시를 담는 비공개 환경 변수입니다. 기존 관리자 계정에서 안전하게 이전하며 저장소에 기록하지 않습니다. 비밀번호 원문은 사용하지 않습니다.

`data/`, `.env`, 데이터베이스 연결 문자열, 관리자 초기 설정 값, 비밀번호, 세션을 공개 저장소에 올리지 마세요.

무료 서비스의 사용량 한도가 적용됩니다. Render 서버는 유휴 상태에서 잠들 수 있어 다음 접속 시 시작을 기다릴 수 있습니다. GitHub의 main 브랜치에 변경을 올리면 Render가 자동으로 다시 배포합니다.

GitHub Pages는 로그인 서버를 실행하지 못하므로 이 앱의 배포 대상으로 사용하지 않습니다.

레벨·뱃지·랭킹은 예시이며 출석·로그인·즐겨찾기는 실제 계정 기록을 사용합니다.
